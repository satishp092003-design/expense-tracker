# Expense Tracker

A simple command-line expense tracker built in Python. Add expenses, view them, and see a summary of spending by category — all saved locally so your data persists between runs.

## What it does
- Add an expense with amount, category, and an optional note
- View a list of all recorded expenses
- See a summary of total spending grouped by category
- Data is saved automatically to a local JSON file

## Tech stack
- Python 3
- JSON for local data storage (no database required)

## How to run it
1. Clone this repository
2. Make sure you have Python 3 installed
3. Run the script:
   \`\`\`
   python tracker.py
   \`\`\`
4. Follow the on-screen menu to add, view, or summarize expenses
